# Sample Agent

This miniature fixture exists only to demonstrate the community validator.

## How it works

It receives local text and returns the same text. It performs no external action.

## Requirements

Node.js 20 or newer. No model, API, account, or external service is required.

## Run locally

Run `npm start -- "hello"`. This local path is free and works offline.

## Safety and permissions

The fixture reads only its command-line input and has no external permissions.

## Limitations

This is a validation fixture, not a production agent.

## Tests

Run `npm test`. Tests make no network calls and have no cost.
