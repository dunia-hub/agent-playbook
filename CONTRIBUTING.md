# Contributing to Agent Playbook

Thank you for contributing to Agent Playbook.

We welcome new agents, improvements to existing agents, documentation, tests, examples, translations, and beginner friendly explanations.

## Before contributing

Small fixes can be submitted directly through a pull request.

For a new agent or a large change, open an issue first so the idea and scope can be discussed.

## Ways to contribute

You can:

- Build a community agent
- Improve an official workshop agent
- Add tests or example outputs
- Fix bugs
- Improve documentation
- Make setup easier for beginners
- Add support for another ecosystem
- Improve accessibility or translations
