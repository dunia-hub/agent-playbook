## Safety concepts

- **Preview before action:** the default run proposes options without writing a file.
- **Explicit confirmation:** `--confirm` identifies the exact slot the user approved.
- **Deterministic checks:** code handles time ranges and conflicts instead of trusting
  model prose.
- **No silent delivery:** generating an ICS file does not send an invitation or add an
  event to a calendar.
