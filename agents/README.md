# Official Workshop Agents

This directory contains the ten agents built during Dunia Hub's first Agent Playbook workshop series.

| Workshop | Agent | Purpose |
|---|---|---|
| 01 | Untangle Agent | Turns a messy brain dump into a clear action plan |
| 02 | Smart Contract Reader | Explains smart contract code and highlights important permissions and risks |
| 03 | Research Agent | Collects sources and produces a structured research summary |
| 04 | Booking Agent | Checks availability and prepares calendar bookings |
| 05 | Gas Agent | Reads and explains blockchain network fee information |
| 06 | Multilingual WhatsApp Support Agent | Handles support questions across multiple languages |
| 07 | Swap Agent | Prepares a controlled testnet token swap |
| 08 | x402 Pay Per Call Agent | Pays for an API request within defined limits |
| 09 | Music Agent | Creates playlists from moods, activities, and preferences |
| 10 | Multichain Agent Team | Coordinates specialist agents across blockchain ecosystems |

Each agent will include:

• A clear explanation of how it works  
• A guided version that does not require a paid AI service  
• Setup and run instructions  
• Example inputs and outputs  
• Tests  
• Ideas for extending the agent
